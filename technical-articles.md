
# Technical News Search Engine

## Overview

Built a Java-based application to process and analyze a collection of 100 technology-related articles. The project focused on applying object-oriented programming and data structures to organize article data and support analytical queries.

## Project Goals

- Process and organize technology-related articles
- Implement object-oriented programming concepts
- Enable users to search and analyze article data
- Generate statistics and insights from the dataset
- Provide a simple menu-driven interface for querying the data

## Functionality

The application included features for:

- Searching for specific articles or topics
- Identifying trending topics over a specified time period
- Analyzing the popularity of specific topics
- Generating general database statistics
- Querying article information through a menu-driven interface
